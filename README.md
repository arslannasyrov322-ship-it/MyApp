# Простой веб-сервер на Python

Минимальный HTTP-сервер на чистом Python, который выводит приветствие и путь, по которому перешел пользователь. Настройки задаются через переменные окружения.

## Локальный запуск

```bash
python app.py
```
Сервер запустится на порту `8080` (по умолчанию). Проверить можно в браузере: `http://localhost:8080`.

### Переменные окружения
* `PORT` — порт сервера (по умолчанию `8080`).
* `APP` — имя приложения в тексте приветствия (по умолчанию `LMS`).

---

## Запуск через Docker

1. **Сборка образа:**
   ```bash
   docker build -t my-app .
   ```

2. **Обычный запуск:**
   ```bash
   docker run -p 8080:8080 my-app
   ```

3. **Запуск со своими настройками (порт 9000 и имя Test):**
   ```bash
   docker run -p 9000:9000 -e PORT=9000 -e APP="Test" my-app
   ```
